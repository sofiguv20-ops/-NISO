# Duo Connect

Quiero crear una aplicación móvil para parejas llamada provisionalmente NISO.

La aplicación debe ser una experiencia privada para dos personas dentro de una pareja. Quiero combinar principalmente cuatro conceptos:

Un calendario compartido y organización de pareja inspirado en Howbout.

Seguimiento menstrual compartido y personalizable inspirado en Stardust.

Ubicación compartida y funciones de seguridad/ubicación inspiradas en Life360.

Funciones románticas y de conexión entre la pareja, pero sin convertir la aplicación en una copia de Couple Joy.

La aplicación debe sentirse como una aplicación moderna, bonita, íntima y juvenil para parejas, pero no infantil.

IMPORTANTE:

No quiero copiar diseños, textos, nombres, iconos ni código de otras aplicaciones.

Solo quiero utilizar como referencia las funciones y la experiencia de usuario.

Toda la información privada debe estar protegida.

Los usuarios deben controlar exactamente qué información comparten con su pareja.

Una cuenta individual solo puede estar vinculada a una pareja a la vez en la primera versión.

Quiero que la aplicación sea mobile-first y esté diseñada principalmente para utilizarse desde un teléfono.

Quiero una navegación inferior sencilla.

La aplicación debe funcionar correctamente en Android y iPhone mediante una interfaz web responsive/PWA.

Utiliza una arquitectura que permita posteriormente convertirla en una aplicación móvil nativa.

Utiliza Supabase para autenticación, base de datos, almacenamiento y actualizaciones en tiempo real.

NO construyas todavía todas las funciones avanzadas.

Primero crea la arquitectura general, el sistema de usuarios, el sistema de pareja y la navegación principal.

La navegación principal deberá tener:

🏠 Inicio
📅 Calendario
🌙 Mi ciclo
📍 Ubicación
💕 Nosotros
⚙️ Ajustes

Quiero que la aplicación tenga una estética elegante, romántica, moderna y ligeramente Pinterest-like, con mucho espacio en blanco, tarjetas redondeadas, iconos simples, microanimaciones suaves y una interfaz muy fácil de entender.

No quiero que parezca una aplicación médica ni una aplicación empresarial.

Primero construye únicamente la estructura base y déjame revisar el diseño antes de añadir las funciones avanzadas.
